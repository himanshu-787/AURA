# AURA: Autonomous Unified Research & Reasoning Agent

An AI research agent that takes a complex question, retrieves evidence
from documents and the web, reasons over it, and produces a
citation-backed report.

## Status
Phase 0: project setup

## Roadmap
- v0.1: documents + question -> answer with citations (basic RAG)
- v0.4: planner, researcher, critic agents
- v1.0: full platform (FastAPI, Docker, CI/CD, evaluation)
